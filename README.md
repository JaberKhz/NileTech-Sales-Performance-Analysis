# 📊 NileTech Sales & Team Performance Analysis

## 📝 Project Overview
This project is an end-to-end Power BI executive dashboard designed for "NileTech". It provides deep insights into sales performance, product profitability, and sales team efficiency, enabling data-driven decision-making for top management.

## 🛠️ Tools & Technologies Used
- **Power BI:** Data Visualization, Dashboard Design, Page Navigation.
- **Power Query:** Data Cleaning, Transformation, and Handling Orphan Records.
- **DAX:** Custom Measures (e.g., DISTINCTCOUNTNOBLANK, DIVIDE, CALCULATE).
- **UI/UX Design:** Custom branding (Nile Navy Blue & Cyan), rounded corners, and soft shadows.

## 💡 Key Business Problems Solved
1. **Data Quality Enhancement:** Identified and resolved "Orphan Records" in the sales fact table (System ID: 9999) using Power Query to ensure 100% accurate revenue reporting.
2. **Sales Team Efficiency:** Created active rep tracking logic using `DISTINCTCOUNTNOBLANK` to calculate average revenue per active sales representative.
3. **App-like Experience:** Implemented seamless Page Navigators for an interactive and executive-friendly user experience.
